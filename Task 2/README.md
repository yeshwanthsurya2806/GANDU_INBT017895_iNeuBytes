# 📌 Project Overview

**PulseCare - Doctor Appointment Booking System** is a responsive healthcare web application developed as part of the **iNeuBytes Web Development Internship (Task 2)**.

The application allows users to browse doctors, search specialists, view detailed doctor profiles, book appointments, generate appointment confirmations, and manage appointment history using **Local Storage**.

The project focuses on creating a clean user interface while implementing dynamic functionality using JavaScript.

---
